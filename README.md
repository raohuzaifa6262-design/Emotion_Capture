# Emotion Capture & NLP Analysis

Natural Language Processing (NLP) workflow for emotion classification from textual data.

## Overview
This project processes text datasets to classify human emotions (e.g., joy, sadness, anger, love) using Python, Pandas, and NLTK text processing pipelines.

## Contents
- `Emotion.ipynb`: Jupyter notebook containing text preprocessing, tokenization, text cleaning (regex), and exploratory data analysis.
- `train.txt`: Emotion-labeled textual dataset.

## Requirements
- Python 3.8+
- Pandas
- NumPy
- NLTK
- Matplotlib & Seaborn
